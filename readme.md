# Wisconsin Cannabis News Search

A simple web app to search for recent news (last month) about cannabis, legalization, policy, or general news in Wisconsin.

## How to Use

1. Click the **Search News** button.
2. View the latest news articles as clickable links.

## Deployment

### GitHub Pages

1. Fork or clone this repository.
2. Push all files (`index.html`, `style.css`, `app.js`) to your repo.
3. Go to your repo settings > Pages > Source: select `main` branch and `/root`.
4. Your site will be live at `https://yourusername.github.io/your-repo-name/`.

### Netlify

1. Go to [Netlify](https://netlify.com) and sign up.
2. Click **Add new site** > **Import an existing project**.
3. Connect your GitHub repo or drag and drop the project folder.
4. Netlify will deploy your site and give you a live URL.

---

**No build step is needed. All code runs in the browser.**
